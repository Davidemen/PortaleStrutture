| Cell | Sheet behaviour | Fixed behaviour | Clause | Numeric impact on golden case |
|---|---|---|---|---|
| `edometrico!J`, `Elastico_centrale_Newmark!S`, `500!L` | Layer range lookup falls back to 0 past the last layer's `to` or in a stratigraphy gap; `IFERROR(...,0)` then silently contributes 0 to that depth slice's settlement instead of erroring. | `soil_layers.layer_at(layers, z)` raises `KeyNotFound` ("la stratigrafia non copre la profondità...") when no layer covers `z`. `legacy=True` reproduces the sheet (`None` = zero contribution) for `legacy_compat` tools that need to match a cached case where the profile happens not to reach the full depth grid. | docs/architecture-batch2.md §7 | None on the cached golden cases: all 3 sheets' layer tables extend past the depth grid's max (e.g. edometrico's last layer reaches 11 890 cm > the 5 000 cm grid), so the gap is never actually hit in any golden case. |
| `Elastico_Timoshenko_Goodier_3!H11` | `Es = Σ_{i=1..4} Gi·(Fi−Ei) / H` — sum hard-wired to exactly 4 layers, but always divides by the full `H`; when the profile needs a 5th layer within `[0, H]` (as the sheet's own golden case does: `strato 5` covers `[450, H=500]`), that portion's thickness is silently dropped from the numerator while still counted in the denominator. | `soil_layers.weighted_modulus(layers, h)` sums every layer's overlap with `[0, h]`, for any number of layers, and raises `KeyNotFound` if the table does not cover `[0, h]` at all (never silently short-changes the average). | docs/architecture-batch2.md §7 "T-G-3 H11" | Golden case (`docs/specs/geo-cedimenti-elastico.md` Tool 2): sheet's `H11 = 138.8 kg/cmq` (legacy, only strato 1-2 counted: `(180·160 + 140·290)/500`); fixed `weighted_modulus` on the same 3 real layers (zero-thickness strato 3/4 rows omitted, strato 5's `[450,500]` portion included) gives `166.8 kg/cmq` (16.3559 MPa) — **+20.1%**. Reproducing the legacy figure is the consuming tool's job (`geotechnics.cedimenti_elastico`, `legacy_compat=True`, by calling `weighted_modulus` on only the sheet's first 4 rows); this shared module always computes the fixed value.
