Source: `2xxxx_Plinti isolati.xlsx`, sheets `INPUT`/`CHECKS` (`build/cellmaps/fond-plinti-isolati/`).
NTC2018 §6.4.2/§6.4.3 (fondazioni superficiali), EC2 §7.2/§7.3 (limitazione tensioni/fessurazione).

All fixes are controlled by `legacy_compat` on `PlintoIsolatoInput` (`True` reproduces the sheet

## Da verificare (kept in both modes, no fix applied)

- **Ties in the family envelope XLOOKUP** (`INPUT!N16`, `R16`, …): when two combos in a family tie
  on the governing value, the sheet's `XLOOKUP(...,0,1)` returns the first match; `shared.load_table`
  matches this convention exactly (first-appearance order), so there is no divergence to record —
  documented here only because it is easy to assume otherwise.

## Not ported: one-way shear / punching

The isolated-footing workbook never computes a one-way shear or punching check (unlike
`plinti_pali`, which has dedicated `taglio`/`punzonamento` result groups): `docs/specs/
fond-plinti-isolati.md` has no shear/punching cell, and `docs/architecture-batch2.md` §1 does not
list `shared.ec2_shear` among this package's reuses or `taglio`/`punzonamento` among its result
groups. `fond-plinto-isolato` therefore covers exactly what the sheet covers: bearing, sliding,
overturning and the flexural/SLS design. Needed shear/punching design for isolated footings would
be new scope, not a divergence, and should reuse `shared.ec2_shear` (`v_rd_c`, `control_perimeter`)
the same way `plinti_pali`/`ca_punzonamento` do.

## Cell-mapping correction (not a spreadsheet divergence, a tooling one)

`build/cellmaps/fond-plinti-isolati/input.txt` mislabels the `Asx`/`Asy`/`Φmin` block: it reports
cell `T16` as `Asx` (formula referencing `T13`) where the workbook's actual cell is `T15`; the real
`T16` is `Asy` (references `T14`), and the real `Φmin` cell is `T25`, not `T26`. Verified directly
against the `.xlsx` with `openpyxl` (`ws['T15'].value`, …). `strutture`'s own `flessione.py` was
never affected (it composes `As required <- Mx,SLU` / `Mx,SLU <- SLU-family envelope` directly, not
through the cellmap text); only `tests/fixtures/gen_plinti_isolati_oracle.py`'s read list needed the
correction. Reported for whoever next reads that cellmap file.
